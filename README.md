# Portfolio — Design & Development

Personal site showcasing design-forward web projects. Built with Y2K Revival aesthetic: chrome text effects, gradient meshes, and custom cursor interactions. ## What This This portfolio site demonstrates ability build visually engaging web experiences without relying on heavy frameworks. I built this using vanilla JavaScript, CSS, and HTML — no React, no Vue, no framework at all. reason deliberate: I wanted prove understanding core web technologies, not just framework-specific patterns. ## Features - **Custom Cursor:** Context-aware cursor with trail effect that changes shape when hovering interactive elements. - **Theme Toggle:** Light/dark mode switch that persists across sessions. - **Scroll Animations:** Fade-in effects with staggered delays for project cards and process steps. - **Chrome Text:** Gradient text with shimmer animation for visual interest. - **Reduced Motion:** Respects `prefers-reduced-motion` system setting. - **Responsive:** Adapts to different screen sizes with mobile-friendly layout. ## Design Decisions color palette uses Y2K-inspired colors: warm cream background, muted accent colors, and gradient meshes for depth. custom cursor designed to feel like a real-world pointer with trail effect showing movement history. theme toggle uses sun/moon icons to clearly indicate current state. scroll animations use staggered delays to create rhythm and guide user through content. chrome text effect uses gradient with shimmer animation to create visual interest without being distracting. ## Technical Details - Vanilla JavaScript — no frameworks - CSS custom properties for theming - IntersectionObserver for scroll animations - requestAnimationFrame for smooth cursor movement - localStorage for theme persistence - Google Fonts: Space Grotesk (UI) JetBrains Mono (code/data) ## Running Locally No build step needed.
